# 일렉트레이너 홍반장 | PLC의 입력 COM, 출력 COM 결선 및 측정

부제: COM은 어디에 물려야 측정이 쉬울까?

- 대상: 고2~3 전기과, 전기기능장·과정평가형 PLC 실습 준비생 (PLC 결선 경험 1~2회)
- 길이: 약 10분 (이론 애니메이션 A 4분 + 실기 촬영 S 6분, 2~3분마다 번갈아)
- 학습 목표: ① 양방향 포토커플러 입력이 극성과 무관한 이유를 말한다 ② 입력 COM을 24G에 두면 측정이 쉬운 이유를 테스터 값으로 설명한다 ③ 릴레이 출력에서 COM에 전원을 걸고 흑색 리드를 램프 공통(PN)에 두는 점검법을 수행한다 ④ 진짜 전압과 유도(허상)전압을 구분한다
- 웹 시뮬레이터: https://claude.ai/artifact/DVueFkhLPg3gxNa7kBfVC6 (선생님 배선 시뮬레이터의 PLC 연결부와 같은 결선·표기)

표기: **[A]** = Claude가 만드는 애니메이션 / **[S]** = 선생님 촬영 / **[N]** = 내레이션

**연출 원칙** (1편과 동일)
- 질문으로 열고 끝에 답 확인
- 결선도는 선 하나씩 쌓아 올리기, 전위는 색으로(24V 빨강, 24G 파랑, L1 갈색, 기준선 파랑)
- 애니메이션 ↔ 실제 테스터 화면 교차, 같은 구도로 "권장 결선 / 반대 결선" 좌우 분할
- "일부러 거꾸로 결선하기" 코너: 위험 장면 없이 측정값이 이상하게 나오는 것만 보여 줌
- 220V 측정 컷은 차단 상태에서 결선, 한 손 측정, 클로즈업으로만

## 0. 오프닝 훅 (0:00~0:30)

**[S]** 실습반 PLC. 램프는 꺼져 있는데 테스터에 220V가 떠 있음. 다음 컷, 스위치를 안 눌렀는데 입력 단자에 24V.

**[N]** 램프는 꺼졌는데 220V, 스위치는 안 눌렀는데 24V. PLC가 고장일까요? 아닙니다. COM을 어디에 물렸느냐의 문제입니다. 10분 뒤엔 이 숫자를 보고 바로 이유를 말할 수 있게 됩니다.

**자막:** 고장일까, 결선일까?

## 1. 입력부 안에는 무엇이 있나 (0:30~1:40)

**[A]** 장면 1: PLC 입력 단자 I00과 COM 사이를 확대. 저항 → LED 두 개가 서로 반대 방향으로 붙은 모양 → 빛 → 포토트랜지스터. 전류 화살표를 오른쪽으로 흘리면 위 LED, 왼쪽으로 흘리면 아래 LED가 켜짐.

**[N]** PLC 입력 안에는 포토커플러가 들어 있습니다. 이 기종은 LED 두 개를 반대 방향으로 붙인 양방향형이라, 데이터시트에는 "AC 입력형"이라고 적혀 있기도 해요. 전류가 어느 쪽으로 흐르든 하나가 켜지니까, COM을 24V에 두든 24G에 두든 입력은 동작합니다.

**자막:** 극성 무관. 단, 정격은 DC 24V (AC 220V 넣으면 소손)

## 2. 그럼 어느 쪽이 좋을까: 테스터로 보기 (1:40~3:30)

**[A]** 장면 2: 좌우 분할 결선도. 왼쪽 = COM↔24G 점퍼, 24V POWER OUT → 스위치 공통선. 오른쪽 = COM↔24V, 24G → 스위치 공통선. 두 쪽 모두 흑색 리드는 24G, 적색은 I00.

**[S]** 실제 테스터 화면. 왼쪽 결선: SS_A OFF 0V → ON 24V. 오른쪽 결선(일부러 거꾸로): OFF 24V → ON 0V.

**[N]** 왼쪽은 스위치를 누르면 24V가 I00으로 들어옵니다. "0이면 OFF, 24면 ON". 오른쪽은 동작은 똑같이 되는데, COM의 24V가 포토커플러를 거쳐 단자까지 올라와 있어서 안 눌렀을 때 24V, 누르면 0V가 됩니다. 거꾸로 읽어야 하죠. 시험장에서 이걸 "스위치 불량"으로 착각하는 학생이 많습니다.

**자막:** 입력 COM → 24G, 스위치 공통 → 24V. 누르면 전압이 들어온다

## 3. 하나 더: 입력선이 외함에 닿으면 (3:30~4:10)

**[A]** 장면 3: 24G가 외함 접지에 묶인 그림. 입력선 피복이 벗겨져 외함에 닿는 순간. 왼쪽 결선은 입력 OFF 유지(누르면 퓨즈 동작), 오른쪽 결선은 버튼을 안 눌렀는데 입력 LED가 켜지고 램프가 켜짐.

**[N]** 24G를 외함에 접지해 둔 제어반이라면 차이가 더 큽니다. COM이 24V인 결선은 입력선 하나가 외함에 닿기만 해도 입력이 켜집니다. 기계가 혼자 움직이는 쪽으로 고장 나는 거죠.

## 4. 출력은 접점 하나일 뿐 (4:10~5:30)

**[A]** 장면 4: 릴레이 출력 내부 = 코일 + 접점 하나. COM0~COM3 점퍼(DR20SU). 접점은 전압을 만들지 않는다는 자막.

**[S]** 결선: F1 차단 상태에서 COM0~COM3 점퍼 → 전원 한쪽, Q00~Q04 → PL_A~E → 램프 공통 PN → 전원 다른 쪽.

**[N]** 출력은 PLC 안의 스위치 하나입니다. COM 쪽에 전원을 걸어 주면, ON 됐을 때 Q 단자로 전압이 "나갑니다". 측정할 때 흑색 리드는 램프 공통 PN에 고정. ON이면 220V, OFF면 0V.

**자막:** 출력 COM ← 전원, 흑색 리드 ← 램프 공통 PN

## 5. "일부러 거꾸로" 코너 (5:30~7:30)

**[S]** 자막 "오늘은 선생님이 일부러 거꾸로 잽니다". 출력 COM을 PLC 전원 N측(F1-2)에, 램프 공통을 F1-1에 둔 상태에서 흑색을 습관대로 F1-2에 대고 측정. 램프 꺼짐인데 220V. 리액션 한 번.

**[A]** 장면 5: 램프 필라멘트를 지나 L 전위가 Q00까지 "새어 들어온" 모습. 전류가 거의 없으면 저항 양 끝 전압이 같다는 화살표.

**[N]** 꺼져 있는데 220V. 이건 진짜 전압이에요. 램프를 거쳐 반대편 전원이 단자까지 와 있는 겁니다. 그리고 켜면 0V. 숫자가 거꾸로죠.

**[S]** 이어서 PL_A를 빼고 측정 → 일반 테스터에 50V 안팎, 숫자가 흔들림. 테스터를 LoZ로 바꾸거나 램프를 다시 끼우면 0V 근처로 떨어짐.

**[A]** 장면 6: 떠 있는 전선 옆에 220V 전선. 두 선 사이 정전용량 기호. "힘 없는 전압 = 유도(허상)전압".

**[N]** 이번 50V는 가짜입니다. 어디에도 안 붙은 선이 옆 전선에서 전압을 옮아 온 거예요. 전류를 흘릴 힘이 없어서 LoZ 테스터로 재면 사라집니다. 꺼진 램프에서 보이는 220V는 진짜, 떠 있는 선의 수십 V는 가짜. 이 둘을 구분하면 오판이 줄어듭니다.

**자막:** 진짜 전압은 LoZ로 재도 남는다 / 유도전압은 사라진다

## 6. 안전 한 컷 (7:30~8:10)

**[A]** 장면 7: F1-1(L1), F1-2(L3) 두 선 모두 대지전압이 있다는 그림.

**[N]** 이 실습반은 L1과 L3 두 상에서 220V를 받습니다. 둘 다 충전된 선이라, 출력이 꺼져 있어도 램프 한쪽은 살아 있어요. 램프 교체와 결선 변경은 반드시 F1을 내리고 합니다. 집처럼 L과 N으로 받는 단상 전원이라면 COM을 L에 둬야 꺼졌을 때 램프가 무전압이 됩니다.

## 7. 실습 판정 (8:10~9:30)

**[S]** 학생 손 화면. 흑색 24G → 적색 I00~I05 순서로 찍으며 0/24V 확인. 흑색 PN → 적색 Q00~Q04, 출력 강제 ON/OFF로 220/0V 확인. 한 곳은 램프를 일부러 빼 둠 → "220V 나오는데 안 켜짐 → 램프 쪽 불량" 판정.

**[N]** 출력에 220V가 나오는데 램프가 안 켜지면 PLC는 정상, 램프나 공통선이 문제입니다. 0V면 프로그램이나 출력 쪽을 봅니다. 측정 한 번으로 갈라집니다.

## 8. 마무리 (9:30~10:00)

**[A]** 정리 카드: 입력 COM ← 24G / 출력 COM ← 전원, 흑색 ← PN / 진짜 전압 vs 유도전압.

**[N]** 결선도와 측정을 직접 바꿔 볼 수 있는 시뮬레이터와 확인 문제 10개는 웹 페이지에 있습니다. QR 찍고 풀어 보세요.

## 내부평가 문항 10개

1. 양방향(AC 입력형) 포토커플러 입력에서 COM 극성이 상관없는 이유는? → LED 두 개가 역병렬이라 어느 방향 전류에도 하나가 켜짐
2. COM=24G, 스위치 공통선=24V. SS_A ON에서 I00–24G 전압은? → 24V
3. COM=24V, 스위치 공통선=24G. 스위치 OFF에서 I00–24G 전압은? → 약 24V (거꾸로 읽힘)
4. NPN 출력 근접센서를 연결할 때 입력 COM은? → 24V (PNP는 24G)
5. 24G를 외함에 접지한 경우, 입력선 지락 시 입력이 저절로 ON 될 수 있는 결선은? → COM=24V 결선
6. "AC 입력형" DC 24V 입력 단자에 AC 220V를 걸면? → 소손될 수 있음
7. COM0~3=F1-1(L1), 램프 공통=F1-2(L3). Q00 ON에서 Q00–L3 전압은? → 220V
8. COM=F1-2(L3), 램프 공통=F1-1(L1). Q00 OFF인데 Q00–L3가 220V인 이유는? → 램프를 거쳐 L1 전위가 단자에 와 있음 (진짜 전압)
9. 램프를 뺀 상태, 출력 OFF에서 일반 테스터로 50V 정도가 보였다. 해석과 확인 방법은? → 유도(허상)전압, LoZ 테스터나 부하 연결 후 재측정
10. L1·L3 두 상 220V 출력 회로에서 램프 교체 시 올바른 것은? → F1 차단 후 교체 (출력 OFF만으로는 한쪽이 충전 상태)

## 선생님 설명에 대한 기술 보충 (자료에 반영함)

- "AC 입력 포토커플러" = 양방향 전류를 받는다는 뜻이고, 입력 정격은 DC 24V. AC 220V 입력과 혼동하지 않도록 자막으로 명시.
- 입력 COM=24G 결선은 측정 편의 외에 지락 시 안전측(입력이 저절로 켜지지 않음)이라는 근거가 더 있음. 단 NPN 센서는 COM=24V가 필요한 예외.
- "허상전압"은 두 가지로 나눠 설명: 반대 결선에서 꺼진 램프를 거쳐 보이는 220V는 진짜 전압(LoZ로도 남음), 램프가 빠져 떠 있는 선의 수십 V는 유도전압(LoZ로 사라짐).
- 실습반 전원이 F1-1(L1)·F1-2(L3) 두 상이면 두 선 모두 충전부라, 흑색을 램프 공통 PN에 두면 COM을 어느 쪽에 두든 ON 220V로 읽힘. 측정이 거꾸로 되는 건 흑색을 N측(F1-2)에 고정했을 때. "흑색은 PN" 습관을 함께 가르치는 것을 권장.
