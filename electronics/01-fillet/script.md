# 파일럿 1편 대본: 좋은 필렛 vs 불량 필렛

- 대상: 고1~2 전자과, 납땜 경험 0~5시간
- 길이: 약 10분 (이론 애니메이션 A 4분 + 실기 촬영 S 6분, 2~3분마다 번갈아)
- 학습 목표: ① 좋은 필렛의 모양 3가지를 말할 수 있다 ② 흔한 불량 5가지를 눈으로 구별한다 ③ 내 납땜을 스스로 판정하고 고친다
- 과정평가형 연계: 전자기능사 실기(조립·납땜 작품) 평가 항목 대비, 내부평가 문항 10개 포함(맨 아래)

표기: **[A]** = Claude가 만드는 애니메이션 / **[S]** = 선생님 촬영 / **[N]** = 내레이션

**연출 원칙 (해외 채널 기법 참고, 내용은 독자 제작)**
- 질문으로 열고 끝에 답 확인 (GreatScott!식 구조)
- 단면 그림은 한 번에 하나씩 쌓아 올리기 (Ben Eater식 빌드업)
- 애니메이션 ↔ 현미경 실물 컷 교차, 유튜브 챕터 표시 (Phil's Lab식 구성)
- "일부러 망치기" 코너로 웃음 포인트, 단 위험한 장면 없이 안전한 불량만 (ElectroBOOM식 실패 데모를 교실용으로)
- 합격/불합격은 늘 같은 구도·조명의 좌우 분할 화면 (제조사 납땜 교육 영상식)
- 대본은 외우지 말고 작업하며 말하기, 한 컷 10초 안팎 (EEVblog식 현장감)

## 0. 오프닝 훅 (0:00~0:30)

**[S]** 현미경 화면. 납땜된 핀 두 개를 나란히. 하나는 매끈한 산 모양, 하나는 동그란 구슬 모양.

**[N]** 둘 다 납은 붙어 있습니다. 그런데 하나는 합격, 하나는 불합격입니다. 오늘 10분이면 왜 그런지 눈으로 바로 구별할 수 있게 됩니다.

**자막:** 어느 쪽이 합격일까? (정답은 3분 뒤)

## 1. 필렛이 뭐예요? (0:30~1:30)

**[A]** 장면 1: PCB 단면. 기판, 구리 패드, 스루홀, 부품 다리가 차례로 나타남. 납이 녹아 흘러 들어가 다리와 패드 사이를 채우며 오목한 산 모양이 됨. "필렛(fillet)" 라벨.

**[N]** 납땜에서 필렛은 부품 다리와 패드 사이를 채운 납의 모양입니다. 이 모양만 봐도 납이 금속에 제대로 붙었는지 알 수 있어요.

## 2. 핵심 한 가지: 젖음 각도 (1:30~3:00)

**[A]** 장면 2: 물방울 비유. 왼쪽은 깨끗한 유리 위 납작하게 퍼진 물, 오른쪽은 기름 묻은 면 위 동그랗게 맺힌 물. 이어서 납으로 바꿔 보여줌. 접촉각을 호로 표시: 좋음은 작은 각(오목), 나쁨은 90°가 넘는 각(볼록).

**[N]** 납이 금속을 좋아하면 넓게 퍼지고, 싫어하면 동글게 뭉칩니다. 이걸 '젖음'이라고 해요. 잘 젖은 납은 가장자리가 얇게 퍼져서 각도가 작고, 젖지 못한 납은 구슬처럼 각도가 커집니다.

**자막:** 좋은 필렛 = 오목, 얇은 가장자리, 작은 각도

## 3. 좋은 필렛 체크 3가지 (3:00~4:00)

**[S]** 현미경으로 좋은 필렛을 돌려 가며 촬영. 손가락(또는 핀셋 끝)으로 세 곳을 가리킴.

**[N]** 오프닝 정답, 왼쪽이 합격입니다. 체크할 건 세 가지예요.
1. 모양이 오목하다. 산 모양으로 패드 끝까지 얇게 퍼진다.
2. 다리 윤곽이 보인다. 납에 파묻혀 사라지지 않는다.
3. 표면이 매끈하다. 유연납은 반짝, 무연납은 살짝 무광이어도 정상.

## 4. 직접 해보기 (4:00~6:00)

**[S]** 인두 온도 설정 화면(무연 약 350°C 전후, 사용 납 규격 기준) → 인두 팁을 패드와 다리에 동시에 대기 → 1~2초 뒤 납 공급 → 납 떼고 → 인두 떼기. 한 번은 정상 속도, 한 번은 느리게.

**[A]** 장면 3(짧게, 화면 구석 PIP): 열이 패드와 다리 둘 다로 퍼지는 화살표. "둘 다 데워야 납이 둘 다에 붙는다."

**[N]** 순서는 '데우고, 넣고, 납 떼고, 인두 떼고'. 인두로 납을 녹여 바르는 게 아니라, 금속을 데워서 납이 스스로 흘러 들어가게 하는 겁니다.

## 5. 불량 5가지 (6:00~8:30)

**"일부러 망치기" 코너.** 자막 "오늘은 선생님이 일부러 망칩니다". 선생님이 인두를 납에만 대고 문지르기, 납을 잔뜩 먹이기 등으로 불량을 직접 만들고, 결과를 현미경으로 보며 "아… 이건 아니죠" 하는 짧은 리액션. 효과음 1개 정도. (감전·화상·연기 과장 같은 위험 개그는 넣지 않음)

각 불량마다 **[A]** 단면 1컷(3~4초) → **[S]** 실물 현미경 1컷(좌: 합격 / 우: 불량, 같은 구도·조명) → 원인 한 줄 → 고치는 법 한 줄.

| 불량 | 이렇게 보인다 | 원인 | 고치는 법 |
| --- | --- | --- | --- |
| 냉납 | 회색, 거칠거칠, 금 간 듯 | 열 부족, 굳기 전에 흔들림 | 플럭스 추가 후 다시 녹이기 |
| 과납 | 구슬처럼 볼록, 다리 윤곽 안 보임 | 납을 너무 많이 넣음 | 솔더윅으로 덜어내기 |
| 소납 | 패드가 드러나고 구멍이 덜 채워짐 | 납 부족, 너무 빨리 뗌 | 납 조금 추가 |
| 브리지 | 옆 핀과 납이 이어짐 | 과납, 팁 끌기 | 솔더윅, 인두로 갈라내기 |
| 고드름 | 뾰족한 뿔 | 인두를 늦게 떼거나 플럭스 부족 | 플럭스 바르고 다시 녹이기 |

**[N]** (불량마다) 이렇게 생겼고, 이래서 생기고, 이렇게 고칩니다.

## 6. 스스로 판정 (8:30~9:30)

**[S]** 학생 작품(얼굴 없이 손과 기판만) 3개를 현미경으로. 화면에 3초 멈춤 + "합격? 불합격?" 자막 → 정답 공개.

## 7. 마무리 (9:30~10:00)

**[A]** 체크리스트 카드: 오목 / 윤곽 / 매끈 + 불량 5가지 아이콘.

**[N]** 오늘 기준표는 웹 페이지에 있습니다. QR 찍고 판정 퀴즈 10문제 풀어 보세요. 다음 편은 칩 부품(SMD) 납땜입니다.

## 촬영 체크리스트 (선생님용)

- [ ] 현미경 또는 매크로 렌즈 화면 녹화 (스마트폰 + 클립 매크로렌즈도 가능)
- [ ] 위에서 내려다보는 손 작업 화면 (스마트폰 거치대)
- [ ] 좋은 필렛 시편 2개, 불량 5종 시편 각 1개, 학생 작품 3개
- [ ] 인두 온도 표시가 보이는 컷
- [ ] 내레이션: 조용한 교실에서 스마트폰 녹음도 충분 (입에서 20cm)

## 내부평가 문항 10개 (초안)

1. 납땜에서 '필렛'이 가리키는 것은? → 부품 다리와 패드 사이를 채운 납의 모양
2. 좋은 필렛의 모양은 오목한가, 볼록한가? → 오목
3. 접촉각(젖음 각도)이 90°보다 크면 의미하는 것은? → 젖음 불량
4. 좋은 필렛 체크 3가지를 쓰시오. → 오목한 모양, 다리 윤곽이 보임, 매끈한 표면
5. 무연납 필렛이 약간 무광이면 불량인가? → 아니다, 정상일 수 있다
6. 납땜 순서를 바르게 나열하시오. → 패드·다리 가열 → 납 공급 → 납 떼기 → 인두 떼기
7. 회색이고 거칠며 금 간 듯한 접합의 이름과 원인은? → 냉납, 열 부족 또는 굳기 전 움직임
8. 다리 윤곽이 보이지 않는 구슬 모양 접합은? → 과납
9. 옆 핀과 납이 이어진 불량을 고치는 도구는? → 솔더윅(또는 인두로 갈라내기 + 플럭스)
10. 인두로 납을 녹여 '바르면' 안 되는 이유는? → 금속이 데워지지 않아 납이 젖지 않음(냉납)
